# Bear Attack

Bruno the bear sneaks up on people in his territory: hiding in bushes, creeping
through the dark, and wearing ridiculous costumes. See [DESIGN.md](DESIGN.md)
for the full game plan.

## Controls

| Key | Action |
|---|---|
| Arrows / WASD | Move |
| Ctrl (hold) | Sneak: slow and silent |
| Shift (hold) | Run: fast but loud |
| Space | Pounce |
| R | Restart level |
| Esc / Q | Quit |

## Setup

```sh
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
```

## Run

```sh
python -m bearattack
```
